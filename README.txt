PREVIEW:
Open index.html in a browser. For the best preview, use Chrome.

PUBLISH ON YOUR EXISTING GITHUB REPOSITORY:
1. Open https://github.com/qadrizameer2105-max/ALQADIR.GITHUB.IO
2. Upload the index.html file and the complete assets folder to the repository ROOT.
3. If GitHub asks whether to replace an existing index.html, choose replace.
4. Commit changes to the main branch.
5. Open Settings > Pages. Choose Deploy from a branch, branch main, folder /(root), then Save.
6. Wait a few minutes and open:
   https://qadrizameer2105-max.github.io/ALQADIR.GITHUB.IO/

IMPORTANT:
- Keep the folder name exactly "assets".
- Keep the homepage file name exactly "index.html" (all lowercase).
- The package price and dates are taken from the supplied poster. Confirm current price, seats, flight and package inclusions before accepting bookings.
- The reference package poster with another company's branding is not displayed as a Tajim offer.
